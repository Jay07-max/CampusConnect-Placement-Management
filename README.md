# 🎓 CampusConnect – Student Placement Management System

## 📌 Project Overview
CampusConnect is a web-based Student Placement Management System designed to help students and placement coordinators manage placement-related information efficiently. It provides a centralized platform for organizing student details and placement records.

## 🚀 Features
- Student placement information management
- Student details management
- Web-based user interface
- Backend developed using Python Flask
- Easy access through a web browser

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** SQLite (if configured in the project)
- **Version Control:** Git and GitHub
- **Deployment:** Render

## ⚙️ Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Jay07-max/CampusConnect-Placement-Management.git
   ```

2. Open the project folder:
   ```bash
   cd CampusConnect-Placement-Management
   ```

3. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   ```

4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

5. Run the application using the appropriate Flask command configured in the project.
